# 用戶端憑證控制台驗證（2026-09-23）

本次完成程式與隔離測試，**未在正式 CA 簽發或撤銷憑證**。

## 已驗證

- 主機 Python 測試使用臨時 Root／中繼 CA、OpenSSL CA 資料庫與獨立目錄，實際簽出裝置憑證、建立可解開的 PKCS#12 與 ATAK DPK，再撤銷該憑證；新 CRL 包含其序號，DPK 被移至封存目錄。未連接正式 TAK 使用者資料庫。
- 憑證清冊測試涵蓋管理員憑證排除、到期日與「少於 1 天」、過期與撤銷分開標示、指紋變更時拒絕操作；群組測試涵蓋 In／Out 分離、無法讀回既有 TAK 狀態時拒絕修改。
- 使用不公開通訊埠的一次性 TAK 容器，對既有裝置憑證執行 `UserManager.jar certmod -s`。實際輸出位於 stderr；修正後主機解析器讀回使用者名稱、SHA-256 指紋及 `local-test` 的 In／Out 權限，與憑證檔一致。測後已停止並移除一次性容器與測試時啟動的資料庫。
- Flask 容器的 12 項測試涵蓋管理頁 Basic Auth、CSRF、憑證清冊與詳細頁渲染、替代主機通訊埠、CRL 復原表單，以及批次撤銷前停止同一 DPK 的全部 QR 分享。
- `docker compose --profile sharing config --quiet`、Python 語法檢查與 `git diff --check` 通過。正式 `CoreConfig.xml` 的 8443 connector 仍無 `crlFile`；`security/tls/crl` 仍存在。
- 憑證清冊原本的狀態標籤 CSS 少一個 `)`，使後面的格線與表單樣式未被瀏覽器解析；已修正並改為逐張憑證卡片。Chrome 在約 1591px 顯示三欄、768px 與 375px 顯示單欄；375px 無水平溢出。實測搜尋、隱藏不相符卡片、多選後撤銷按鈕啟用，以及取消選取。沒有提交撤銷操作。
- In／Out 群組介面改為未指派、In、Out、In + Out 四個清單。寬螢幕把未指派放在上方、三個權限清單並排；768px 為兩欄，375px 為單欄，均無水平溢出。隔離瀏覽器測試確認拖曳後的 `in_group`，以及新增群組、點選後移至 Out 所產生的 `out_group` 表單值。正式管理頁與已註冊憑證詳情頁皆讀到三欄排列；沒有送出任何正式群組變更。
- 外部群組 CSS 一度被管理頁 CSP 擋下；已將 `style-src 'self'` 加入 CSP，Flask 測試確認須經 Basic Auth 才能取得 CSS，Chrome 重新載入後樣式正常。
- 清冊新增卡片／清單切換及「隱藏已撤銷」篩選。正式管理頁在 1591px 預設清單、375px 預設卡片，視窗寬度切換時會更新；兩種寬度的手動選擇分別記住。實測顯示模式切換保留已選憑證，兩筆已撤銷憑證可隱藏，與搜尋同時套用時顯示空結果提示，重新整理後篩選仍保留；375px 無水平溢出。測試後清除選取，未提交撤銷。
- 清冊統計列依目前條件更新顯示、隱藏與總筆數；搜尋、30 天內到期及隱藏撤銷的符合數量只在相關條件啟用時出現。正式清冊在隱藏撤銷時顯示 1、隱藏 2、總計 3；搜尋 `crl` 並維持隱藏撤銷時，符合搜尋 2、顯示 0、隱藏 3、其中已撤銷 2。勾選 30 天內到期時符合數量為 2。測試後清空搜尋欄並取消到期篩選。

## 當前環境限制

本機 Windows 的 TCP 排除範圍目前含 `8369–8468` 與 `8669–8768`，無法綁定原主機通訊埠 8443、8765、8766。因此本機 Git 忽略的 `.env` 暫用 `10043`、`10065`、`10066`。TAK Server 仍對熱點提供 `8089`，容器內 8443／8765／8766 沒變。`tak-db`、`tak-server`、`share-admin`、`share-public` 均健康；`http://127.0.0.1:10066/certificates` 回應 HTTP 200 並讀到 3 筆現有用戶端憑證，公開服務 `192.168.137.1:10065/healthz` 也回應 HTTP 200。從正式 TAK 成功讀回其中 1 筆已註冊憑證的群組；另 2 筆舊的 CRL 探測憑證沒有 TAK 使用者身分，詳細頁正確顯示無法讀回並停用群組變更。

尚未執行新裝置的正式 CA 簽發、Android DPK 匯入、熱點裝置 QR 下載，或正式憑證的 8089 撤銷測試。Mumble 與 MediaMTX 本次未重啟。重開機後先執行 `netsh interface ipv4 show excludedportrange protocol=tcp` 檢查原通訊埠是否釋放；若要改回 8443／8765／8766，移除或調整本機 `.env` 後再重建相關容器。接著確認熱點 `192.168.137.1`、啟動 Docker Desktop、執行 `docker compose --profile sharing up -d --no-build tak-server share-admin share-public`，並重新啟動前景憑證管理程式。需要從 Android 使用 QR 下載時，對當前公開通訊埠開立熱點防火牆規則。
